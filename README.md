# David Godinez — HR Technology Portfolio

A responsive, accessible static portfolio focused on HCM implementation, payroll operations, employee support, and public service.

## Publish free with GitHub Pages

1. Create a new GitHub repository and upload this project.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The included workflow will publish the `dist` folder automatically after every push to `main`.

To preview locally, open `dist/index.html` in a browser.

## Update content

- Page copy: `dist/index.html`
- Styling: `dist/assets/styles.css`
- Interactions: `dist/assets/app.js`
- Résumé download: `dist/assets/David_Godinez_Resume.pdf`
